# TP-01 测试工具（极简版）

给生产 / 售后用的精简版，**两个页面：键盘 / 灯光、固件升级**。没有命令面板 / 弹唱 / 预设 / RAW。

## 功能

- 连接 TP-01：**蓝牙 BLE / USB MIDI 二选一**（页面顶部切换）
- 标准 88 键键盘
- **音符**：按住发 Note On，松开发 Note Off（可选通道、力度）
- **灯光**：按下点亮、松开熄灭（可选颜色）
- **检验**：88 键全灰，收到设备按键后变绿，集齐后大字显示 **PASS**（进入时自动全屏横屏）
- 全部熄灭 / 全部亮红 / 全部亮绿 / 全部亮蓝（逐灯发送，间隔 20ms）/ All Notes Off
- **固件升级**（仅蓝牙）：
  - 选 `.ble` 升级包直接发送；选 `.BIN` 时自动打包（已带 16 字节头直接用，Keil 原始程序按 `iap_pack.py` 规则自动加头）
  - 自动生成 8.3 合规文件名（如 `APP_V101.BIN`），可下载生成的 `.ble`
  - 升级前自检（帧头 / 每帧 CRC16 / 帧号 / 整体 CRC32），并显示对象、版本、帧数
  - 弹窗确认后逐帧发送：支持断点续传、断线自动重连、停止、防锁屏
  - 进度 / 速度 / 剩余时间，错误码中文提示
- 简版日志（可展开，便于排障）
- 空格 = 紧急停止（All Notes Off + 全部熄灭）

## USB MIDI 连接说明

页面顶部把连接方式切成 **USB MIDI**，点「连接」：

- 浏览器会请求 MIDI 权限，授予后自动列出 USB MIDI 端口；有多个设备时会弹出选择框。
- 手机上需要 **OTG 转接线**（手机/平板需支持 USB Host），把 TP-01 接到 USB 口。
- 支持 **Chrome / Edge / 三星浏览器**（Android 与桌面均可）；**iOS 不支持**。
- 若找不到设备：检查 OTG 线、换一根数据线、确认设备被识别为 USB MIDI（而不是仅供电）。

> USB MIDI 直接收发标准 MIDI 消息，不经过 BLE 包头；界面操作与蓝牙完全一致。
> **注意：固件升级只支持蓝牙**——琴的 IAP 只从蓝牙模块那一路接收升级数据，USB 下「开始升级」会禁用。

## 固件升级说明

1. 用蓝牙连接 TP-01（USB 不支持升级）。
2. 选择升级文件：
   - `.ble`：固件组用 PC 工具生成的成品包，原样发送。
   - `.BIN`：带 16 字节头的直接用；Keil 原始程序会自动加头，需要选升级对象并填版本号（必须**大于琴里现有版本**）。
3. 自检通过后点「开始升级」，在弹窗里确认。
4. 琴会回「稍等」并重启进入升级模式（约 1 秒），随后自动逐帧传输；完成后琴自行安装，**不要关机**。

要点：

- 一个 `.ble` 对应一次升级；多个文件等第一个完成后再发。
- 断线重连后从第 0 帧续传，琴会回复从哪一帧继续。
- 默认 **20 字节包 / 0ms 间隔**，与 PC 工具速度基本一致；想更快可把包长改成 244（需模块支持）。
- 若出现 `0x13`（写入失败）或大量重发，把「包间隔」调到 20 / 50 ms，或勾选「写入带确认」；仍失败给琴断电重启。
- 若进度停在 0%、反复重发同一帧，用 **128 / 256** 块大小重新打包后再试。
- 错误码：`10` 文件格式不对 · `11` 文件名不对 · `12` 空间不足 · `13` 写入失败 · `14` 文件校验失败。

## 部署

这是一个纯静态目录，**部署时只需要拷贝整个 `simple/` 文件夹**。

> ⚠️ 必须通过 **HTTPS** 访问（Web Bluetooth 的安全上下文要求）。详见上一级目录的 `deploy/README.md`。

### 方式 1：放到任意静态服务器 / 宝塔 / Nginx

把 `simple/` 里的全部文件上传到站点目录（例如 `/var/www/tp01-simple/`），配置 HTTPS 即可。

### 方式 2：GitHub Pages

把 `simple/` 里的文件放到仓库根目录（或 `docs/`），在 Settings → Pages 里启用即可。

### 方式 3：本地预览（开发用）

```bash
npx serve simple
# 或
python -m http.server 8000 -d simple
```

浏览器打开 `http://localhost:端口`（localhost 属于安全上下文，可用蓝牙）。


## 说明

- 这个版本是**独立自包含**的，不依赖上一级目录的任何文件，可以直接整包部署。
- 设备端命令仍是 TP-01 协议：灯光 `A1/A0`、音符标准 Note On/Off、固件升级 `F0 7D 58 48 …`，BLE-MIDI 打包与完整版一致。
- 如果后续完整版有改动、希望同步到这个极简版，需要手动把 `js/midi-codec.js`、`js/firmware.js`、`js/tp01.js`、`css/style.css` 重新拷贝过来。
